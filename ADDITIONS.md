# gaussianparticle

Light-scattering simulations of Gaussian-random-sphere particles made of different cosmic-dust and ice materials, built on the **SIRIS4** geometric optics framework. This repository adds Python tools on top of SIRIS4 for:

- **Batch runs** of the multi-particle code (`sirismp`) over a library of 12 materials and two particle sizes, with automatic extraction of the polarization maximum.
- **Simulated-annealing fitting** of material parameters (refractive index, albedo, mean free path) to a target scattering curve.
- **Shape handling**: merging Gaussian-sphere meshes generated by `GS` into a single `.off` mesh for `sirismp`.
- **Plotting** of shapes and scattering results.

> **Based on SIRIS4.** The scattering code in this repository comes from the [SIRIS4 framework](https://bitbucket.org/planetarysystemresearch/siris4-framework) by Karri Muinonen, Timo Väisänen, Hannakaisa Lindqvist, Julia Martikainen and Antti Penttilä (Department of Physics, University of Helsinki). It is distributed under the GPL-3.0 license (see `LICENSE.txt` and `COPYING`), and this repository keeps that license. For the SIRIS4 programs themselves (siris1p, siris2l, sirismp, GS), their input options and the references to cite, see the original documentation in [`README.md`](README.md).

## Setup

1. Build the SIRIS4 programs (needs `gfortran`; `sirismp` also needs the CGAL and Boost C++ libraries):

   ```
   make GS              # Gaussian-sphere shape generator
   make singleparticle  # siris1p
   make multiparticle   # sirismp
   ```

2. Install the Python dependencies (Python 3, NumPy, Matplotlib and others) in a virtual environment:

   ```
   python3 -m venv my_env
   source my_env/bin/activate
   pip install -r requirements.txt
   ```

## What's added

### 1. Batch runs over materials: `multi-particle/example/run_siris_particles.py`

This script runs `sirismp` for every combination of material and particle size, and summarises the results in one CSV file.

**Materials** (refractive index *n + ik* at red-light wavelengths):

| Material | n | k |
| --- | --- | --- |
| Halley-like dust | 1.98 | 0.48 |
| Amorphous silicate (forsterite) | 1.677 | 0.0044 |
| Water ice | 1.308 | 1.43e-8 |
| Carbon dioxide ice | 1.41 | 1.05e-6 |
| Iron-rich pyroxene | 1.675 | 0.0212 |
| Olivine | 1.743 | 0.066 |
| Amorphous carbon | 2.14 | 0.805 |
| Pyrrhotite (FeS) | 1.70 | 1.86 |
| Iron-rich olivine (fayalite) | 1.85 | 0.00077 |
| Cosmic organic refractory | 1.98 | 0.2677 |
| Tholin ice | 1.540 | 0.0012 |
| Titan tholins | 1.557 | 0.0009 |

**Sizes:** `mesh_scale` 20 and 200. The wavelength is set to 2π, so `mesh_scale` corresponds directly to the size parameter.

**What it does for each run:**

1. It creates a folder `batch_runs/<material>_<size>/` and copies the mesh (`siris-output.off`) and the diffuse-scatterer phase matrix (`outputS.out`) into it.
2. It writes an `input.in` for that material and size (100 000 rays, diffuse scatterers on, beam covering the whole particle).
3. It runs `sirismp`.
4. From the resulting `outputS.out`, it finds the maximum of the degree of linear polarization, −S12/S11, and the scattering angle where that maximum occurs.

**Output:** each folder holds the full `sirismp` output (`outputS.out`, `pmatrix.out`, `details.out`). The summary of all runs goes to `siris_redlight_results.csv`, with one row per material and size: n, k, the angle of the polarization maximum, and its value.

**Usage:**

```
cd multi-particle/example
python3 run_siris_particles.py
```

The script expects the compiled `sirismp` at `multi-particle/sirismp` and a mesh `siris-output.off` in the example folder. With `EXPERIMENTAL_MFP_ON = 1` it also reads a mean-free-path distribution file, `~/dists/cdfconstant04dist.txt`. Edit the `SETTINGS` block at the top of the script to change the sizes, number of rays or files used.

### 2. Fitting by simulated annealing: `multi-particle/example/anneal_sirismp.py`

This script searches for the material parameters that make `sirismp` reproduce a target S11 phase function.

- **Parameters fitted:** real and imaginary refractive index (`REF_REAL`, `REF_IMAG`), single-scattering albedo (`ALBEDO`) and mean free path (`MFP`) of the diffuse scatterers.
- **Cost function:** the mean squared difference between the model S11 and the target S11, after interpolating the model onto the target angles.
- **Algorithm:** at each step the script perturbs the parameters at random and runs `sirismp`. It accepts the new parameters if they fit better, or with probability `exp(−ΔE / T)` (the Metropolis criterion) if they fit worse. The temperature starts at `T = 1.0` and is multiplied by 0.95 each step, for 50 steps. The best parameters found are printed at the end.
- **Input template:** `input_template.in` is a `sirismp` input file with placeholders (`{REF_REAL}`, `{REF_IMAG}`, `{DIFFUSE_ON}`, `{ALBEDO}`, `{MFP}`) that the script fills in on every run. Runs happen in the `anneal_runs/` folder.

**Making a target:** `make_target.py` converts an existing `outputS.out` (scattering angle, S11) into `target.npz`, the format `anneal_sirismp.py` reads. Fitting to a SIRIS result whose parameters you already know is a good way to test that the fit recovers them.

**Usage:**

```
cd multi-particle/example
python3 make_target.py        # outputS.out -> target.npz
python3 anneal_sirismp.py
```

> **Note:** the path to `sirismp` is currently hard-coded as `/home/dnels/master/multi-particle/sirismp` at the bottom of the script. Change it to your own path before running.

### 3. Single-particle annealing outline: `anneal.py`

`anneal.py` is an early outline of the same simulated-annealing approach for the single-particle code `siris1p`. Its helper functions (`write_input`, `parse_output_chi2`) and settings are not filled in yet, so it does not run as is. `anneal_sirismp.py` is the working version.

### 4. Shape tools: `GS/`

- **`merge_objs_to_off.py`** merges several `.obj` meshes (for example several Gaussian spheres written by `GS`) into a single `.off` mesh, so that a group of particles can be used as one `sirismp` shape:

  ```
  python3 GS/merge_objs_to_off.py shape1.obj shape2.obj ... merged.off
  ```

  > The merged file contains geometry only. `sirismp` reads materials from the face colours in the `.off` file (see the *Off file* section of [`README.md`](README.md)), so material codes have to be added before the mesh can be used.

- **`plot.py`, `multplot.py`**: plotting scripts for the generated shapes.
- **`GS-input.in`**: the GS input file, modified for these runs.
- **`siris-output*.obj`**: example Gaussian-sphere shapes produced by `GS`.

### 5. Plotting

- `multi-particle/example/plot_script.py` plots the scattering results of the multi-particle runs.
- `single-particle/plot_script.py` plots the scattering results of the single-particle runs.
